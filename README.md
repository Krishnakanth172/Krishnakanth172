
# Krishna Kanth Kodanganti

**Machine Learning Systems | AI Infrastructure | Inference Engineering**

M.S. Data Science @ University of California, San Diego

I work at the intersection of machine learning, systems engineering, and production AI infrastructure. My interests include efficient model inference, distributed serving, foundation-model adaptation, ML observability, and reproducible performance evaluation.

- **ML Systems:** PyTorch, JAX, TensorFlow, CUDA, TensorRT, vLLM, and model-serving architectures
- **Foundation Models:** Fine-tuning, PEFT/LoRA, evaluation, experiment tracking, and reproducible ML pipelines
- **Distributed Data Systems:** Kafka, Spark, Airflow, streaming pipelines, data quality, and analytical storage
- **Production Engineering:** Docker, Kubernetes, CI/CD, observability, automated testing, and reproducible environments
